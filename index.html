Battery Characterization Suite

Four Python tools that turn lithium-ion cycler data into the parameters a battery management system's model needs: state of charge, open-circuit voltage, hysteresis, and a 1RC to 5RC Thevenin equivalent circuit.

My role
Sole author. Generalised from analysis I wrote during the Maruti Suzuki internship and published as open source on my GitHub.
Evidence
On a synthetic cell with known ground truth: open-circuit voltage recovered to within 0.90 mV (worst case; 0.26 mV RMS), hysteresis to within 0.53 mV of a 13 to 24 mV signal, and a known 2RC circuit to within 1.1 % from 0.5 mV noise.
Tests
1,173 automated tests; 46 run the real analysis backends end to end in CI.

  • NumPy
  • SciPy least_squares
  • pandas
  • Streamlit
  • pytest

Infrared target simulator

A prototype that reproduces thermal signatures for testing FLIR cameras: Arduino PWM firmware switching MOSFET-driven resistive heater channels, checked against the camera's own thermal image.

My role
Built the prototype at Leapedge Aerospace and Defense (January 2026) under a senior engineer's guidance: firmware, driver channels, thermal validation, and a draft scalability analysis.
Evidence
Programmed heating patterns compared against captured thermal-camera output. Photographs and dimensions are not published.

UI Element Scraper

A Java tool that signs into a web application and crawls it depth-first, inventorying every interactive control it can reach, including the ones inside modals, tabs and menus that a flat scan misses.

My role
The crawler is my design and build: state-graph strategy, termination bounds, inventory. A companion test-execution layer is unfinished, developed with a senior engineer.
Evidence
Run on a local demo app for this site: 30 controls in 33 s, 20 of them behind a modal, a tab and a menu, every locator on a stable id. 217 unit tests, no browser needed.
